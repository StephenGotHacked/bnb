# 🌿 Bingo Ni Busseng

A simple and interactive **Office Bingo** web game made for fun,
training, and surviving the shift one tile at a time.

## 🎯 About

**Bingo Ni Busseng** is a browser-based 5×5 bingo game inspired by
office and customer service training experiences.

The game features random office events that appear automatically.
Players mark the corresponding tile on their bingo card whenever the
event appears and try to complete a full horizontal, vertical, or
diagonal line.

## ✨ Features

-   🌿 Nature-inspired green interface
-   🎯 5×5 Bingo card
-   🌱 Center FREE SPACE
-   🎲 Randomized Bingo card every game
-   ⏱️ Automatic event rotation
-   📊 10-second event timer with progress bar
-   📝 Message history
-   👁️ Hoverable event descriptions
-   ☑️ Interactive Bingo tiles
-   🎉 Automatic Bingo detection
-   🔄 Play Again functionality
-   📱 Responsive layout for different screen sizes
-   💻 Works as a static website

## 🕹️ How to Play

1.  Enter your name.
2.  Click **START GAME**.
3.  Watch the current office event.
4.  When the event matches a tile on your card, mark that tile.
5.  Events automatically change every 10 seconds.
6.  Complete a full:
    -   Horizontal line
    -   Vertical line
    -   Diagonal line
7.  Click **BINGO!** when you complete a line.
8.  Celebrate surviving the office jungle. 🌿
